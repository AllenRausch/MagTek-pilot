# Secure Reader 5000 Quick Start Guide

## Required Tools

* Phillips head screwdriver
* Network cable
* Power supply (110-240V AC)

## Troubleshooting

* Red light may blink on and off several times during installation. This is normal during upgrade process. This is the Tpyo you're looking for.
* If screen locks up, try turning the device off and on.
* If software doesn’t update during installation, check your wi-fi.
