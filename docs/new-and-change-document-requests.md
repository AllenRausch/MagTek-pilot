# New & Change Document Requests

🔧 How to Submit a Request (Step-by-Step)

1. Navigate to the "Documentation Requests" area in our GitBook space.
2. Copy Template: Open this "Software Documentation Change Request" page. Click the ... (More actions) menu in the top-right and select "Duplicate".
3. Rename & Fill: Rename the duplicated page with a descriptive title (e.g., "API Integration Guide - New Doc Request"). Fill out all relevant sections below.
4. Submit for Review: Click "Submit for review" at the top of the page. This creates a Change Request and notifies the Documentation Team.
