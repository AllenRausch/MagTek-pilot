# GitBook Demo Walkthrough

## Scenario 1: Quick Edit – Fix a Typo

{% stepper %}
{% step %}
### Navigate to the document

Open the document you want to edit.
{% endstep %}

{% step %}
### Click “Edit”

Enter the editor for the document.
{% endstep %}

{% step %}
### Find and fix the typo

Locate the typo and correct it.
{% endstep %}

{% step %}
### Save or “Request review”

Save your changes or submit the document for review.
{% endstep %}

{% step %}
### Merge (if approved)

Once approved, merge the change into the published content.
{% endstep %}
{% endstepper %}

## Scenario 7: “Oh No!” – Recover from Mistakes

{% stepper %}
{% step %}
### Open page history

Access the document's version/history panel.
{% endstep %}

{% step %}
### Select previous version

Choose the previous version you want to restore.
{% endstep %}

{% step %}
### Compare changes

Compare the current version with the selected previous version.
{% endstep %}

{% step %}
### Restore version

Restore the chosen previous version to recover from the mistake.
{% endstep %}
