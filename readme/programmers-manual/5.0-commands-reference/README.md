# 5.0 Commands Reference

## Commands Reference

Complete API reference for all DynaFlex commands.

### Command Groups

#### Transaction Commands (0x10nn)

Commands for processing payments and transactions.

* **0x1001 - Start Transaction** - Initiate payment transaction

#### Settings Commands (0xD1nn)

Commands for device configuration.

* **0xD101 - Get Property** - Retrieve device settings
