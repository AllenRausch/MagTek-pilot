# 1.2.1 USB Connection - Quick Start Guide

## Quick Start Guide: USB Connection

### Overview

Get your DynaFlex device up and running in under 5 minutes. This guide walks you through connecting via USB and running your first command.

### What You'll Need

* DynaFlex, DynaProx, or DynaFlex II Go device
* USB cable (included with device)
* Development environment (Windows, macOS, or Linux)
* Basic understanding of HID communication

### Step 1: Physical Connection

1. Connect the USB cable to your device
2. Connect the other end to your computer
3. Wait for your OS to recognize the device (typically 5-10 seconds)

**Windows Users:** The device should appear in Device Manager under "Human Interface Devices"

**macOS/Linux Users:** Check system logs for HID device enumeration

### Step 2: Understanding USB Reports

The DynaFlex family uses HID (Human Interface Device) protocol with specific report structures:

* **Usage Page:** `0xFF00` (Vendor-defined)
* **Usage ID:** `0x0001`
* **Report Size:** 64 bytes
* **Report Type:** Feature Reports

> **💡 Key Concept:** All communication uses 64-byte Feature Reports, regardless of actual message size.

### Step 3: Send Your First Command

Let's send a simple Echo command (`0xDF01`) to verify connectivity.

#### Request Structure

```
Byte 0: Report ID (always 0x00)
Bytes 1-63: Message data
```

#### Example: Echo Command

```
00 02 00 DF 01 48 65 6C 6C 6F [54 bytes of 0x00]
│  │  │  │  │  └─────────────┘
│  │  │  │  │       "Hello" in ASCII
│  │  │  │  └─ Command ID (0xDF01 = Echo)
│  │  │  └─ Message Type (0x02 = Request)
│  │  └─ Message Length (low byte)
│  └─ Message Length (high byte)
└─ Report ID
```

#### Sample Code (Python)

```python
import hid

# Open device (use your actual VID/PID)
device = hid.device()
device.open(0x0801, 0x0001)  # MagTek VID, device-specific PID

# Prepare echo command
message = bytearray(64)
message[0] = 0x00  # Report ID
message[1] = 0x00  # Length MSB
message[2] = 0x07  # Length LSB (7 bytes)
message[3] = 0x02  # Request message
message[4] = 0xDF  # Command MSB
message[5] = 0x01  # Command LSB (0xDF01 = Echo)
message[6:11] = b'Hello'  # Data to echo

# Send feature report
device.send_feature_report(message)

# Read response
response = device.get_feature_report(0x00, 64)
print(f"Response: {response}")

device.close()
```

### Step 4: Verify the Response

A successful echo will return:

```
00 02 00 DF 01 00 48 65 6C 6C 6F [remaining zeros]
│  │  │  │  │  │  └─────────────┘
│  │  │  │  │  │       "Hello" echoed back
│  │  │  │  │  └─ Status (0x00 = Success)
│  │  │  └──┴─ Command ID confirmation
│  │  └─ Message Type (0x03 = Response)
│  └─ Message Length
└─ Report ID
```

### Troubleshooting

#### Device Not Found

* **Check Device Manager/System Info** - Ensure device is enumerated
* **Try different USB port** - Some ports may have power issues
* **Verify VID/PID** - Use `lsusb` (Linux) or Device Manager (Windows)

#### No Response Received

* **Check timeout settings** - Default is usually 1000ms
* **Verify report ID** - Must be `0x00` for feature reports
* **Check message structure** - Ensure proper TLV encoding

#### Permission Denied (Linux)

Add udev rules:

```bash
# Create file: /etc/udev/rules.d/99-magtek.rules
SUBSYSTEM=="usb", ATTR{idVendor}=="0801", MODE="0666"
```

Then reload:

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```
