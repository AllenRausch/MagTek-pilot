### Feature Details

#### Card Reading Technologies

**Magnetic Stripe Reader (MSR)**

**Available on:** All devices

* Supports ISO/ABA track formats (tracks 1, 2, and 3)
* Encrypted at point of swipe (SRED)
* MagnePrint® fraud prevention
* Bidirectional reading

> **Note:** Track 3 support may vary by region and card type.

**EMV Contact (ICC)**

**Available on:** All devices

* EMV Level 1 & 2 certified
* Supports all major payment schemes:
  * Mastercard (M/Chip)
  * Visa (VIS)
  * American Express (AEIPS)
  * Discover (D-PAS)
  * JCB (J Smart)
  * China UnionPay (PBOC)
  * Interac (Canada)
* Quick Chip support for faster transactions
* Offline PIN verification

**EMV Contactless (PICC)**

**Available on:** All devices

* EMV Level 1 certified contactless
* Kernel support:
  * Kernel 2: Mastercard PayPass
  * Kernel 3: Visa payWave
  * Kernel 4: American Express ExpressPay
  * Kernel 5: JCB J/Speedy
  * Kernel 6: Discover D-PAS
  * Kernel 7: China UnionPay QuickPass
  * Kernel 8: Interac Flash
* Apple Pay, Google Pay, Samsung Pay support
* Maximum transaction limits configurable

**NFC Pass-Through**

**Available on:** All devices

Supports direct communication with NFC tags:

* **MIFARE Classic** (1K, 4K)
* **MIFARE DESFire** (EV1, EV2, EV3)
* **MIFARE Ultralight** (C, EV1, AES)
* **MIFARE Plus** (SL1, SL3)
* **NTag** (213, 215, 216)
* **Type 4** tags

#### User Interface Options

**Touch Display**

**Available on:** DynaFlex, DynaFlex II Go

* Full-color touchscreen
* Signature capture capability
* Custom UI configuration
* PIN entry (PED function)
* Amount confirmation
* Tip and tax entry
* Application selection

**Display Only**

**Available on:** DynaProx

* View-only screen
* Transaction prompts
* Status messages
* No touch input
* No signature capture
* Ideal for attended POS

#### Connectivity Options

**USB**

**Available on:** All devices

* **HID Mode:** Feature reports (64 bytes)
* **CDC Mode:** Virtual serial port
* USB 2.0 Full Speed
* Bus-powered capable
* Vendor ID: `0x0801`
* Product IDs vary by model

**Bluetooth LE**

**Available on:** All devices

* Bluetooth 4.2 or higher
* Low energy for battery life
* Secure pairing with passkey
* Up to 10m range (class 2)
* Bonding support (stored pairings)
* Configurable connection parameters

**WLAN (WiFi)**

**Available on:** All devices

* 2.4 GHz 802.11 b/g/n
* WPA2/WPA3 security
* Static or DHCP IP addressing
* TLS 1.2+ for secure connections
* MQTT and WebSocket support
* Certificate-based authentication
* SoftAP mode for configuration

**RS-232/UART**

**Available on:** DynaFlex, DynaProx

* SLIP protocol framing
* Configurable baud rate
* Hardware flow control
* 3.3V logic levels

{% hint style="danger" %}
**Important:** BCR (barcode) operations not supported on UART interface.
{% endhint %}

**Apple iAP2**

**Available on:** All devices

* Made for iPhone/iPad connectivity
* Lightning/USB-C compatible
* App-specific communication
* Requires AppBundleID configuration

#### Banking Functions (PED)

**PIN Entry Device (PED)**

**Available on:** Touch-enabled devices only

* Secure PIN pad
* TDES and AES PIN encryption
* Online and offline PIN
* Multiple PIN block formats:
  * ISO Format 0
  * ISO Format 3
  * ISO Format 4
* PCI PTS 5.x certified
* Tamper-resistant design

#### Security Architecture

**SRED (Secure Reading and Exchange of Data)**

**Available on:** All devices

* Point-to-point encryption (P2PE)
* DUKPT key management
* Format-preserving encryption
* Encrypted track data
* Encrypted EMV data
* PAN masking with configurable options

**Tamper Detection**

**Available on:** All devices

* Hardware tamper sensors
* Secure boot
* Key zeroization on tamper
* Tamper log recording
* Real-time clock for audit trail

**Device Lock Feature**

**Available on:** All devices (Firmware v102+)

* 4-8 digit passcode protection
* Configurable lock state
* Persistent across resets
* Unlock via passcode or secure command
* Failed attempt tracking

#### Advanced Features

**Manual Card Entry (MCE)**

**Available on:** Touch-enabled devices only

* On-screen keyboard
* PAN entry with Luhn check
* Expiration date entry
* CVV support
* Same encryption as MSR/EMV

**Barcode Reader (BCR)**

**Available on:** All devices

* Camera-based scanning
* 1D and 2D barcodes
* Supported symbologies:
  * QR Code
  * PDF417
  * Code 39, Code 128
  * UPC/EAN
  * Data Matrix
  * See full list
* Configurable encryption

**Value Added Services**

**Apple VAS (Value Added Services)**

* Up to 6 merchant configurations
* Pass data retrieval
* Loyalty and gift cards

**Google Smart Tap (GWST)**

* Up to 6 collector IDs
* Tap & Pay integration
* Transit and loyalty support

**Card Emulation**

**Available on:** All devices (Firmware v102+)

* Emulate ISO 14443 Type A/B cards
* Custom APDU responses
* NFC reader interaction
* Testing and development mode

### Choosing the Right Device

#### For Full-Service POS

**Recommended:** DynaFlex or DynaFlex II Go

* Touch display for customer interaction
* PIN entry capability
* Signature capture
* All payment methods

#### For Attended Countertop

**Recommended:** DynaProx

* Display-only (staff-facing)
* All payment methods
* No customer interaction needed
* Lower cost option

#### For Mobile/Portable

**Recommended:** DynaFlex II Go

* Physical button for power management
* Optimized battery life
* All connectivity options
* Full feature set

### Configuration Requirements

Some features require specific configuration:

#### For EMV Contactless

* Load EMV configuration files
* Load CA public keys
* Set terminal identification
* Configure entry point tables

#### For PIN Entry

* Inject DUKPT keys
* Map PIN encryption keys
* Configure PIN block format

#### For Apple VAS/Google Smart Tap

* Configure merchant IDs
* Set collector IDs
* Load appropriate kernel files
