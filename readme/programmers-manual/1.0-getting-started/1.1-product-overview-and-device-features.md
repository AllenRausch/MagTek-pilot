# 1.1 Product Overview & Device Features

### Introduction

The DynaFlex family represents MagTek's next-generation payment device platform, combining advanced security, multiple payment interfaces, and flexible connectivity options in a compact, versatile form factor. This article provides an overview of the DynaFlex product line and helps you understand which device and features are right for your integration.

**In this article:**

* Overview of the DynaFlex product family
* Key features and capabilities across all models
* Differences between DynaFlex, DynaProx, and DynaFlex II Go
* Understanding feature combinations and configurations
* How to choose the right device for your needs

**Who should read this:**

* Developers starting a new integration project
* Technical architects evaluating payment devices
* Product managers selecting hardware for deployment
* Anyone new to the DynaFlex platform

### The DynaFlex Platform

#### What is DynaFlex?

**DynaFlex** is MagTek's unified platform for secure payment and data capture devices. Rather than separate product lines for different use cases, DynaFlex provides a single, flexible platform that can be configured with the features you need.

**Key Characteristics:**

* **Multi-interface:** Support for contact EMV, contactless/NFC, MSR, and more
* **Secure by design:** PCI PTS certified, tamper-resistant, encrypted data
* **Flexible connectivity:** USB, WLAN, Bluetooth LE, Ethernet options
* **Consistent API:** Same programming model across all models
* **Field-upgradable:** Firmware updates enable new features

#### Platform Benefits

**For Developers:**

* **Learn once, deploy anywhere** - Same API across all DynaFlex models
* **Single codebase** - One integration works on multiple devices
* **Future-proof** - New features via firmware updates
* **Rich SDK support** - C#, Java, Python, JavaScript libraries

**For Businesses:**

* **Investment protection** - Devices evolve with industry standards
* **Flexible deployment** - Choose features per location
* **Simplified inventory** - Fewer SKUs to manage
* **Lower training costs** - Same operation across all models

### Connectivity Options Explained

#### USB Connection

**Characteristics:**

* Direct, wired connection to host
* No driver installation needed (HID mode)
* Reliable, low-latency communication
* Simplest integration path

**Best for:**

* Traditional POS terminals
* Desktop integrations
* Kiosks and attended terminals
* Development and testing

**Connection Types:**

* **USB HID:** Most common, no drivers needed
* **USB CDC:** Serial communication over USB
* **USB iAP2:** iOS/iPad integration

#### WLAN (WiFi) Connection

**Characteristics:**

* Wireless network connectivity
* Connects to existing WiFi infrastructure
* TCP/IP or MQTT communication
* Supports multiple concurrent clients

**Best for:**

* Mobile POS scenarios
* Wireless countertop terminals
* Environments where cables are impractical
* Multi-device deployments

**Network Support:**

* 802.11 b/g/n/ac
* WPA2/WPA3 security
* DHCP or static IP
* SoftAP mode (device acts as access point)

#### Bluetooth LE Connection

**Characteristics:**

* Low-power wireless connectivity
* Pairing with mobile devices
* Short-range (typically 10-30 meters)
* Lower data throughput than WiFi

**Best for:**

* Mobile app integrations
* Tablet-based POS
* Battery-powered scenarios
* Personal device pairing

**Features:**

* BLE 4.2 or higher
* Secure pairing with PIN
* Multiple bonding support
* Connection parameter negotiation

#### Ethernet Connection

_(DynaFlex only)_

**Characteristics:**

* Wired network connection
* Reliable, high-bandwidth
* No wireless interference
* PoE (Power over Ethernet) support on some models

**Best for:**

* Fixed installations
* Enterprise environments
* High-security requirements
* Environments with WiFi restrictions

#### Comparison of Connection Types

| Aspect           | USB          | WLAN           | Bluetooth LE | Ethernet        |
| ---------------- | ------------ | -------------- | ------------ | --------------- |
| **Range**        | Cable length | WiFi coverage  | 10-30m       | Cable length    |
| **Speed**        | High         | High           | Medium       | Very High       |
| **Latency**      | Lowest       | Low            | Medium       | Lowest          |
| **Power**        | Host-powered | Requires power | Low power    | PoE or external |
| **Mobility**     | Tethered     | Mobile         | Mobile       | Tethered        |
| **Complexity**   | Simplest     | Moderate       | Moderate     | Simple          |
| **Multi-device** | 1:1          | 1:many         | 1:1          | 1:many          |

### Security Features

#### PCI Compliance

All DynaFlex devices are certified to rigorous security standards:

**PCI PTS (PIN Transaction Security):**

* PCI PTS 5.x or higher certification
* SRED (Secure Reading and Exchange of Data)
* Hardware-based encryption
* Tamper-resistant enclosure

**What this means:**

* Card data never accessible in clear text
* Physical attacks are detected
* Cryptographic keys protected in secure element
* Meets acquirer security requirements

#### Data Protection

**Encryption:**

* All card data encrypted immediately upon read
* DUKPT (Derived Unique Key Per Transaction) key management
* AES-256 and TDES encryption support
* Encrypted data in transit and at rest

**MagnePrint®:**

* Magnetic card fingerprinting technology
* Detects counterfeit cards
* Additional fraud protection layer

**Secure Communication:**

* TLS for network communication
* Certificate-based authentication
* Message authentication codes (MAC)
* Signed firmware updates

#### Tamper Detection

**Physical Security:**

* Tamper-evident seals
* Active tamper sensors
* Automatic key zeroization on tamper
* Audit logging of security events

**Anti-Tampering Features:**

* Mesh sensors detect case opening
* Voltage monitoring
* Temperature monitoring
* Clock monitoring

### Choosing the Right Device

#### Decision Framework

**Step 1: Identify Your Use Case**

```
Fixed Installation?
├─ Yes → DynaFlex
└─ No → Mobile/Wireless?
    ├─ Yes → Need Battery?
    │   ├─ Yes → DynaFlex II Go
    │   └─ No → DynaProx (external power OK)
    └─ Proximity Only → DynaProx
```

**Step 2: Select Required Features**

Ask yourself:

* Do I need PIN entry? → PED model required
* Do I need signature capture? → Touch model required
* Do I need barcode scanning? → BCR option required
* Do I only need contactless? → Contactless-only may suffice
* Do I need display output? → Touch or Display model

**Step 3: Choose Connectivity**

Consider:

* **USB only:** Simplest, cheapest, reliable
* **USB + WLAN:** Flexibility, backup connection
* **WLAN only:** True wireless, no cables
* **Bluetooth LE:** Mobile device pairing
* **Multiple:** Maximum flexibility, higher cost

#### Common Configurations

**Configuration 1: Basic Countertop**

* Model: DynaFlex
* Features: Contact, Contactless, MSR, Display
* Connectivity: USB
* Best for: Traditional retail POS, low-cost deployment

**Configuration 2: Full-Featured Terminal**

* Model: DynaFlex
* Features: Contact, Contactless, MSR, Touch, PED
* Connectivity: USB + WLAN
* Best for: Restaurant, hospitality, full-service retail

**Configuration 3: Mobile POS**

* Model: DynaProx or DynaFlex II Go
* Features: Contact, Contactless, Touch
* Connectivity: Bluetooth LE or WLAN
* Best for: Tableside, line-busting, mobile sales

**Configuration 4: Unattended Kiosk**

* Model: DynaFlex
* Features: Contact, Contactless, Touch, BCR
* Connectivity: Ethernet or WLAN
* Best for: Self-service kiosks, automated checkout

**Configuration 5: Delivery/Field Service**

* Model: DynaFlex II Go
* Features: Contact, Contactless, MSR, Touch, PED
* Connectivity: WLAN + Bluetooth LE
* Best for: Delivery drivers, field technicians, mobile vendors
