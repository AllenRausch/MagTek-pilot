title: 'Badge: Var J: USB Only'

{% hint style="info" %}
**Device Requirements**

This guide applies to:

* **All DynaFlex family devices** with USB connectivity
* DynaFlex, DynaProx, DynaFlex II Go

**USB Connection Types:**

* USB HID (Human Interface Device) - Most common
* USB CDC (Communication Device Class) - Some models
* USB iAP2 (for iOS integration) - Specific models

This guide focuses primarily on USB HID, which is the standard for payment devices.
{% endhint %}
