**🔢 PIN Security Critical**

PIN data is the most sensitive information in payment processing and requires special handling.

**Mandatory Requirements:**

* PIN must NEVER be accessible in plain text outside secure cryptographic boundary
* Use only PCI-approved PIN pads and encryption methods
* PIN blocks must be encrypted immediately upon entry
* Never log, display, store, or transmit unencrypted PIN data

**Legal Requirement:**

Mishandling PIN data violates PCI PIN Security Requirements and may result in:

* Immediate suspension of payment processing privileges
* Criminal liability
* Substantial financial penalties

For more information, see [PCI PIN Security Requirements](/broken/pages/1a28d5fa84f421216db577414e8e8c117d64b616).
